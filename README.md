# maz-technical-task

## Setup

```bash
pnpm install
cp .env.example .env
pnpm dev
```

Runs on `http://localhost:3000`.

## Scripts

```bash
pnpm build      # production build
pnpm preview    # preview production build
pnpm lint       # eslint
pnpm typecheck  # type check
pnpm format     # prettier
```
